# Oratile Joy Modiseemang — Personal Portfolio

A responsive personal portfolio website built with HTML, CSS and JavaScript.

## Files
- `index.html` — page structure and content
- `style.css` — responsive design and styling
- `script.js` — mobile navigation, copy-email button and small interactions

## Run locally
1. Download/extract the project.
2. Open `index.html` in a web browser.
3. No server or installation is required.

## Before submitting
Replace the placeholder GitHub and LinkedIn links in `index.html` with your real profile URLs.
You can also add your CV as `CV.pdf` and add a download button if required.

## Deploy with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, `script.js` and any other files.
3. In the repository, open Settings → Pages.
4. Select the main branch and root folder.
5. Save and wait for the published link.

## Deploy with Vercel
1. Push the project to GitHub.
2. Import the repository into Vercel.
3. For this plain HTML/CSS/JS project, no build command is needed.
4. Deploy and share the generated URL.
